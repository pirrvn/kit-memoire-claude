# Modèle : transcrire une grille officielle de l'école

/demarrer crée une grille par étape notée par l'école (grille_livrable1.md, grille_livrable2.md, grille_finale.md, ou d'autres noms si l'école découpe autrement) à partir des documents de consignes/originaux/, au format ci-dessous. Les codes servent à noter et à comparer les versions : on ne les change plus ensuite.

~~~
# Grille figée : <étape>

Copie de travail de la grille officielle de l'école (original : consignes/originaux/<fichier>). Version 1.0, figée le AAAA-MM-JJ.

Note de lecture (seulement si la grille d'origine est ambiguë) : ce qui a été déduit, et comment.

| Code | Partie | Critère | Points |
|---|---|---|---|
| A1 | Recherche documentaire | <critère, traduit fidèlement s'il est dans une autre langue> | 1 |
| A2 | ... | ... | ... |
| | | **Total** | **20** |
~~~

Règles :
- Une lettre par étape (A pour le livrable 1, B pour le livrable 2, C pour le mémoire final...), numéros dans l'ordre de la grille d'origine.
- Traduire sans interpréter ; toute déduction (points illisibles, critère ambigu) est signalée dans la note de lecture.
- Si l'école ne fournit pas de grille pour une étape, en construire une à partir des exigences du guide, la faire valider par l'auteur et l'écrire en tête.
