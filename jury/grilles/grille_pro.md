# Grille figée : professionnel du secteur

Point de vue du juge décrit dans .claude/agents/jury-pro.md. Version 1.0 du kit : /demarrer adapte les exemples au secteur étudié (métiers, réglementation), sans changer la structure, puis la grille est figée.

| Code | Critère | 1 point | 3 points | 5 points |
|---|---|---|---|---|
| P1 | Pertinence pour un décideur du secteur | sujet sans enjeu pour les organisations du secteur | enjeu réel mais traité de loin | répond à une question que les décideurs se posent vraiment |
| P2 | Réalisme du terrain et justesse du vocabulaire métier | contresens sur le métier (processus, acteurs, réglementation) | globalement juste, quelques approximations | description exacte et nuancée de la réalité du métier |
| P3 | Actionnabilité | aucune retombée utilisable | pistes générales | enseignements directement utilisables par un décideur |
| P4 | Conformité, éthique et exposition de l'organisation | risque de confidentialité, de réputation ou de non-conformité | risques identifiés mais mal traités | aucun risque pour l'organisation ou les personnes ; cadre réglementaire du secteur et RGPD respectés |
| | **Total** | | | **20** |
