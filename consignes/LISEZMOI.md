# Consignes de l'école

1. Dépose dans **consignes/originaux/** tous les documents officiels de ton école sur le mémoire : guide ou handbook, grilles d'évaluation de chaque étape, fiches pratiques, modèles Word, calendrier.
2. /demarrer les lit et en tire :
   - **SYNTHESE_ECOLE.md** : les règles utiles, classées en neuf sections numérotées, chacune avec un renvoi à la section du guide d'origine ;
   - les grilles figées du jury, dans jury/grilles/.

Le dossier originaux/ n'est pas copié dans git : ce sont des documents de l'école, qui n'ont pas à être publiés. Si l'école publie une nouvelle version d'un document, dépose-la et demande à Claude de mettre la synthèse à jour (les grilles figées ne changent qu'avec ton OK).
